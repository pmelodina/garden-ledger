# บัญชีสวน (Garden Ledger)

เว็บแอปจดรายรับ-รายจ่ายสำหรับสวน พร้อมส่วนบันทึกค่าจ้างพนักงานแยกต่างหาก
ข้อมูลเก็บไว้ในเบราว์เซอร์ของผู้ใช้ (localStorage) ไม่มีเซิร์ฟเวอร์/ฐานข้อมูลภายนอก

## ฟีเจอร์
- บันทึกรายรับ / รายจ่าย แยกตามหมวดหมู่
- สรุปยอดรายเดือน กราฟรายจ่ายตามหมวด
- แท็บพนักงาน: สรุปค่าจ้างที่จ่ายให้แต่ละคน + ประวัติการจ่าย

## เริ่มใช้งาน (Development)

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ที่ `http://localhost:5173`

## Build สำหรับ deploy

```bash
npm run build
```

ไฟล์ที่ build แล้วจะอยู่ในโฟลเดอร์ `dist/` เอาไปโฮสต์บน Netlify, Vercel, GitHub Pages ได้เลย

## หมายเหตุ

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นๆ เท่านั้น
ถ้าเปลี่ยนเครื่อง/เปลี่ยนเบราว์เซอร์ หรือล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหายไป
(ยังไม่มีระบบ sync ข้ามอุปกรณ์)
